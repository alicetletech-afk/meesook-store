# มีสุขส่งถึง — refined v4

เวอร์ชันนี้กลับไปยึดโครงที่อ่านง่ายกว่าเดิม แต่แก้ตามบรีฟใหม่แล้ว

## สิ่งที่ปรับ
- กลับไปใช้ mood **เขียว + เหลือง** แบบเดิม
- พื้นหลังไม่ขาวโพลน ปรับเป็น **โทนครีมอุ่น นุ่มตา**
- CTA LINE เปลี่ยนเป็นแนว:
  - **สอบถามเพิ่มเติม**
  - **ไม่พบสินค้าที่หาอยู่?**
- ปุ่ม LINE ใช้ **เขียว/ขาว**
- เพิ่ม **ไอคอนตะกร้า** ที่กดแล้วเปิดตะกร้าสินค้าลูกค้าได้
- ปุ่มสินค้าแยกเป็น
  - **เพิ่มลงตะกร้า**
  - **สั่งซื้อเลย**
- ข้อความหลักหน้าเว็บปรับเป็น
  - **ส่งฟรีที่ล็อบบี้ IDEO MOBI EASTGATE**
  - **พื้นที่ใกล้เคียงให้สอบถามได้**
- ข้อความเดิม “เลือกสินค้าแล้วส่งออเดอร์เข้า LINE ได้เลย” เอาออกแล้ว
- ข้อความที่ส่งเข้า LINE ถูกจัด format ใหม่ให้อ่านง่าย
- แก้ deep link LINE แล้ว:
  ```js
  const lineUrl = `https://line.me/R/oaMessage/@435ktnsf/?${encodeURIComponent(text)}`
  ```

## Flow ที่ Cody ต้องต่อ
1. ลูกค้ากด `ส่งออเดอร์`
2. validate ชื่อ / ห้อง / โทร
3. save order + order_items ลง Supabase ก่อน
4. ได้ `order_no`
5. build message
6. redirect เข้า LINE

ดังนั้นแม้ LINE จะเปิดไม่ติด ออเดอร์ก็ยังถูกเก็บในระบบแล้ว
